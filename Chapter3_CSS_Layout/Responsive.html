Built with CSS Grid

grid-template-columns and auto-fit with minmax() let a single rule replace per-breakpoint column counts.

  • auto-fit + minmax

    Columns collapse on their own when the container gets narrower, so the card grid needs no extra media queries.

  • Named areas

    The hero uses a two column track named content and card, re-stacked to one row on narrow screens.

  • Fluid type

    Headings use clamp() to scale smoothly between a mobile and a desktop size with no jump.

  • Semantic markup

    Landmarks (header, nav, main, section, footer) do the accessibility work that layout classes cannot.

Built with Flexbox

Breakpoint reference

Mobile first: each rule only adds layout as the viewport grows, which keeps the base CSS small.

Min width Applies to Effect
base mobile single column, stacked nav, 1rem gutter
≥ 40rem tablet 2 column hero, 2 column cards, larger gutter
≥ 48rem laptop sidebar sits beside the main content
≥ 64rem desktop 4 column cards, horizontal nav spacing
≥ 80rem wide container capped and centred
